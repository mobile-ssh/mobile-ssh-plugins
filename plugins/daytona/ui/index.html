Daytona Desktop

A cloud Linux desktop you can watch and drive from your phone.

This plugin talks to the internet. Your Daytona API key and everything you tap or type here are sent to app.daytona.io and your sandbox's proxy — not through an SSH tunnel. The key is stored encrypted on this device and is never put in a URL or written to the log.

A Daytona API key is organisation-wide: anyone holding it can create, read and delete every sandbox in your org.
