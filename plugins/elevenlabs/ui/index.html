ElevenLabs Speak

Have your phone read the remote box out loud.

This plugin talks to the internet. Your ElevenLabs API key and every line you ask it to speak are sent to api.elevenlabs.io — not through the SSH tunnel. The key is stored encrypted on this device and is never put in a URL or written to the log.

ElevenLabs bills per character. Command output is capped (see settings) so a long log tail can't run up a bill by accident.
